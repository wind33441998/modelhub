环境自检 运行自检
1配置 API 密钥 先填密钥，才能选模型
为每个供应商填写并保存 API Key（仅存本机 ~/.modelhub/keys.json）。密钥就绪后，卡2「已连接客户端」里的绑定模型下拉才会出现可选项；未配密钥的供应商其模型为灰禁状态。
2已连接客户端 2 个 · 点卡片选客户端
点任意客户端卡片选定要配置的软件（选中者酸绿描边），再用卡片内 绑定模型下拉 选择当前激活模型。网关同一时刻只有一个激活模型，两个客户端共用该选择。未配密钥的供应商模型为灰禁状态。
3接入客户端
点「更改配置文件」会由本地代理自动定位并修改对应配置文件（~/.claude/settings.json / ~/.codex/config.toml），仅合并新增项、不覆盖你原有内容；写入前自动备份为 .bak，出错可一键还原。

🔗 恢复原配置
⚠️点「更改配置文件」会自动合并上面的 env 段进你现有的 settings.json：仅新增/覆盖 ModelHub 相关 key，不动你原有的 theme、API_TIMEOUT_MS 等其他配置；写入前自动备份为 settings.json.bak，出错可一键恢复。

🔗 恢复原配置
⚠️点「更改配置文件」只改顶层 model / model_provider 两行，并新增/覆盖 [model_providers.modelhub] 段；不动你原有的 [model_providers.deepseek]、[projects.*]、[plugins.*] 等。写入前自动备份为 config.toml.bak。
